Patents

Three US patents in data management

US 2018/0096378

Monitoring dormant accounts for resurrection in an online system

R. Moniz, F. Mehovic · Facebook, Menlo Park · April 2018

An online system monitors advertiser accounts for inactivity. For each dormant account it evaluates whether a past campaign performed well against a benchmark, such as a percentile of cost-per-objective for the account's country, page category, and objective type, and if so sends a recommendation that highlights the past success and links to purchasing a new campaign.

US 6,714,945

System, method, and article of manufacture for propagating transaction processing facility based data and for providing the propagated data to a variety of clients

W. Foote, S. Luttenberg, F. Mehovic, C. Murphy, R. Tait, P. Wright · Sabre, Southlake, Texas · March 2004

Extends the 2000 patent so that data propagated from the TPF-based reservation system can be served to many kinds of clients, allowing new applications to be built on relational technology while the mainframe system continues to operate.

US 6,122,642

System for propagating, retrieving and using transaction processing facility airline computerized reservation system data on a relational database processing platform

F. Mehovic · Sabre, Dallas, Texas · September 2000

Compiles the unstructured passenger name record from the mainframe reservation system on the fly into SQL statements against a relational database, and converts application command syntax the same way, so the legacy and relational systems can coexist during migration.
